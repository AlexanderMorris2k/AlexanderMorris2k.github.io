# Ladders resume site

This folder is a self-contained GitHub Pages site for Alexander Morris's Ladders resume. Open `index.html` or visit `/ladders/` on the published Pages site. The source PDF is provided for download beside the page.

Only files in this folder are needed for the Ladders site. The site uses its own CSS and JavaScript; it does not depend on the repository's main portfolio or the separate Coinbase repository.
